# Reminder types

Help is currently available in English only.

MedTimer offers several reminder types. Choose the one that matches how you want the reminder to be scheduled; these
examples describe app behavior and are not medical advice.

## Time based reminder

Use this when the reminder should occur at selected clock times, such as **08:00 every day**. You can configure the
recurring pattern, including the active weekdays or other supported calendar options.

## Continuous interval reminder

Use this when the reminder should repeat after a fixed duration from a starting moment, such as **every 6 hours**. The
interval continues without restricting reminders to a daily time window until the reminder is deactivated.

## Windowed interval reminder

Use this when the reminder should repeat at intervals during a daily time window, such as **every 4 hours between 09:00
and 21:00**. The pattern starts again each day within the configured window.

## Other reminder types

The choice screen also includes reminders based on a medicine's stock level or expiration date. These are
condition-based reminders rather than clock-time or interval schedules.
