# Manage medicines and reminders

## Pause or resume all reminders for a medicine

Open **Medicine**, select the medicine, and use its options menu to choose **Deactivate all reminders**. The reminder
settings remain saved, but those reminders are inactive. Use **Activate all reminders** from the same menu to resume
them.

## Track stock

Open the medicine and choose **Medicine stock**. Enter the current stock amount and unit. You can also set a refill size
to the size of a new pack of the medicine and use **Refill now** when you buy a new pack. MedTimer estimates stock from
reminder amounts and events it records; review the estimate and correct it when needed.

A reminder's **Reminder threshold** and **Out of stock reminder** settings control stock-related alerts. MedTimer reads
the first number in a reminder amount for stock calculations. If an amount contains no number, stock cannot be reduced.

## Use tags to organize medicines

Create or select tags from a medicine's **Tags** option, then assign them to that medicine. Use the tag filter in the
app to show matching medicines and reminders. A filter can hide other items; clear or adjust it if something appears to
be missing.

Tags can be used to group medicines, but also to manage medicine and reminders for several people.

## Automatic marking is bookkeeping, not confirmation

The **Automatically mark as taken** option is for bookkeeping workflows such as stock tracking. When enabled, the
reminder is not shown as its usual notification and MedTimer records it as taken automatically. That record does not
confirm that a dose was actually taken. Do not use this option if you need the usual reminder or an accurate record of
actual intake.
